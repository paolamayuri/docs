## Conceituação

Retorna os bytes do QRCode para que você renderize em um componente compatível.

---

## Atributos

### Header

<InstanceId />
<Token />
---

## Response

### 200


<Warning>
Pode ser retornado o QR Code em bytes ou, em dispositivos que solicitam a **[Chave de Acesso](/tips/extension-guide)**, o objeto **Challenge** para dar continuidade ao processo de autenticação.
</Warning>

**Exemplo de retorno do bytes do QR Code**
```json
{
  "value": "data:image/png;base64,iVBOR..."
}
```

**Exemplo de retorno para dispositivos que precisam da [Chave de Acesso](/tips/extension-guide)**
```json
{
  "challenge": {
    "allowCredentials": [],
    "challenge": "V275tRcRUu2XjHiF9a6GTKFaZj8G4W_EEuRwdW5zCAM",
    "extensions": {
      "uvm": true
    },
    "rpId": "whatsapp.com",
    "timeout": 600000,
    "userVerification": "required"
  }
}
```

Em casos desse retorno, é necessário concluir a autenticação que foi solicitada por meio do Challenge, para isso temos o endpoint para **[Concluir o Challenge](/instance/passkey-prologue)**

### 405

Neste caso certifique que esteja enviando corretamente a especificação do método, ou seja verifique se você enviou o POST ou GET conforme especificado no início deste tópico.

### 415

Caso você receba um erro 415, certifique de adicionar na headers da requisição o "Content-Type" do objeto que você está enviando, em sua grande maioria "application/json".
